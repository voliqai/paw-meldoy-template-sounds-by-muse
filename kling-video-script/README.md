## 🎬 Production workflow (45 minutes per ad)

```
1. KLING      Generate each scene as a separate clip (5s or 10s, 9:16)
              → Use the prompts in KLING_PROMPTS_COPY_PASTE.md
              → Download WITHOUT watermark (Pro/Professional mode)

2. CAPCUT     Assemble clips in order (free app, phone or desktop)
   or Premiere → Add: voiceover + music + subtitles + logo + CTA
              → Follow the timeline in each script file

3. EXPORT     1080 x 1920 (9:16), MP4, 30fps — see FACEBOOK_ADS_GUIDE.md

4. META ADS   Upload to Ads Manager with the captions copy provided
```

**You do NOT generate the full 30s in Kling at once.** Kling makes 5–10s clips. You generate 4–6 clips and edit them together. Every script below is already split into Kling-ready scenes.

## ⚙️ Kling settings — use these for EVERY clip

| Setting | Value |
|---|---|
| Mode | **Professional Mode** (better faces, animals, motion) |
| Duration | **5s** per scene (10s only where noted) — shorter = fewer AI errors |
| Aspect Ratio | **9:16** (vertical, for Reels/Stories/Feed mobile) |
| Camera Movement | Set in each prompt — or use Kling's Camera Control panel |
| Creativity / Relevance | **0.5** (balanced) — lower if the pet looks distorted |

### Kling golden rules
1. **Never ask Kling to generate text, logos, or phone screens with readable words.** It will garble them. Generate a *blank/glowing phone or TV screen*, then add real app screenshots and text in CapCut.
2. **Same pet in every scene?** Generate Scene 1 first. Take a screenshot of the dog/cat. Use **Image-to-Video** with that image for the next scenes. This keeps the pet identical.
3. **One action per clip.** "Dog looks at door, then lies down, then sleeps while owner leaves and TV turns on" = Kling fails. Split it.
4. **Prompt formula used in this pack:** `Subject + Action + Scene + Camera + Lighting + Mood + Style`
5. If a generation looks wrong (extra legs, melting face), just re-roll. Budget 2–3 generations per scene.

### Universal Negative Prompt (paste in every generation)
```
distorted animal, extra legs, deformed paws, melting face, scary, sad crying, text, watermark, logo, blurry, low quality, cartoon, CGI game look, horror
```

## 🐾 The 3-second rule (Facebook)

85% of people watch Facebook ads **muted** and decide in **3 seconds**.

Every script in this pack therefore starts with:
- **0–3s:** A pet alone looking at the door + big text: *"Leaving your pet home alone?"*
- The product appears by second 5.
- Subtitles are **burned into the video** (not optional).
- The CTA appears in the last 3 seconds AND as text from second 8.
